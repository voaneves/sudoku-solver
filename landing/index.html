Sudoku Solver

Notebook that solves 9x9 Sudoku boards, classic or diagonal, using integer programming.

Jupyter notebook that solves 9x9 Sudoku, classic or diagonal, by modeling it as an integer linear program with PuLP.

  • Open in Colab→

Highlights

  • Solves 9x9 boards given as lists, with 0 for empty cells.

  • Supports the classic rules and the diagonal variant (diagonal=True).

  • Uses PuLP with the CBC solver and prints the solved grid.
